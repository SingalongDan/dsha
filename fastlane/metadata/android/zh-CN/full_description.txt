DSHA 把 DeepSeek Harness 的 Agent 引擎做成了一款 Android 原生应用。

引擎（Node.js 运行时 + 精简的 bionic 前缀）随 APK 分发，首次启动时解包到应用私有目录，随后
**以应用自身的 UID 直接运行** —— 不需要 proot、不需要虚拟机、不需要另装终端应用、也不需要电脑。
界面用 Jetpack Compose 原生渲染，**不是 WebView**。

它不是"简化版客户端"，而是桌面 Web 端的**对等端**：同一个引擎、同一套会话模型、同一批工具、
同一套权限体系。被重写的是交互 —— 单屏 + 会话/轨迹双视图 + 手势 + 抽屉。

功能

- **会话**：流式打字机渲染，定稿后切换完整 Markdown；轮次小点导航；本轮用量面板
  （缓存命中、未缓存输入、含推理的输出、首字延迟、每秒 token、LLM 与工具耗时）；上下文占用指示。
- **轨迹**：彩色操作轨迹条、搜索与类型筛选、行详情，并支持与会话中对应位置的**双向跳转**。
- **手机原生集成**：把文本或文件分享进会话；回合完成与需要确认时发通知；手势导航；可调消息字号；
  品牌自适应图标。
- **输入栏**：权限 / 模型 / 思考强度三枚独立入口（每个模型自带档位）；运行中提供排队与插话。
- **审批与提问**：从底部弹出的浮层，点完即关闭；浮层被划走后可从对话流里重新打开。
- **工具卡**：结束后折叠成一行摘要，运行中显示实时计时。
- **回合失败会说明原因**（模型报错、被阻止、已中止、达到输出上限），而不是静默停止。

注意事项

- **不内置任何 API 密钥**。密钥由你在设置里填写，应用不会在没有凭据的情况下启动引擎；
  密钥以加密方式存储（由 Android Keystore 保护）。
- 应用**只与本机引擎通过回环地址通信**；对语言模型的请求由引擎使用你自己的凭据发出。
- 应用**刻意使用 API 28 作为目标版本**：目标 API ≥ 29 的应用不能执行自己数据目录内的文件，
  而运行随包引擎正需要这一点。这与 Termux 采用的是同一种做法，我们已评估并记录了迁移路径。
- 需要侧载安装，**不上架 Google Play**。
